# Understory Symbol Guidelines

## Selected Symbol

Name: **Understory Symbol - C-F1 Minimal Optical**

Concept: **Suspended Continuation**

Chinese: **未合，不等于终止。**

The detached lower element is not missing. It represents another layer, another thought, another continuation.

## Brand Story Note

Understory Symbol:

Suspended Continuation.

A visible structure is never the whole story.

The lower element represents another layer of thought, another question, another continuation.

The symbol reflects:

- Understory: beneath the obvious.
- 问溯: following the question deeper.
- One More Question: the thought continues.

## Website Integration

The symbol is integrated into the existing `site-identity` lockup without redesigning the wordmark.

Keep:

- Existing typography.
- Existing header layout.
- Existing navigation rhythm.
- Existing editorial restraint.

The symbol should sit quietly before the wordmark. It should never become a decorative badge or large app icon.

## Spacing And Alignment

Use the current website lockup as the source of truth:

- Symbol size: about `1.13rem` on desktop.
- Mobile symbol size: about `1.08rem`.
- Gap to wordmark: about `0.52rem`.
- Align optically to the wordmark midline, with a tiny downward correction.

## Usage

Use black or currentColor on light paper backgrounds.

Use white only on dark backgrounds.

Use brand green for accent applications, not as the default header mark.

## Do Not

- Do not redraw the symbol.
- Do not remove the detached lower element.
- Do not make it more like a Q or question mark.
- Do not use it as a large decorative motif.
- Do not alter the wordmark typography.
- Do not add decorative effects, shadows, gradients, or outlines.
