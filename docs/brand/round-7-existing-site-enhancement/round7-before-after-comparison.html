Understory / Round 7

Keep the site. Add only what earns its place.

Purpose

This round treats the existing Understory website as the source of truth. Round 6 becomes an idea library only: four small mechanisms are tested inside the current site language, then checked for possible future logo seeds.

01 / Diagnostic

Existing foundations to preserve

These are not optional. Each experiment uses the current wordmark, palette, typography, header structure, reading width, and case flow.

Typography

Georgia for identity and major headlines; Inter/system for body and metadata.

No new font system. Refinement must come from spacing, rules, hierarchy, and existing sizes.

Wordmark

Lowercase serif `understory`, quiet and editorial.

The wordmark remains the brand anchor. No symbol is installed or placed beside it.

Color

Warm paper, off-white surface, black-brown text, restrained green.

Green stays structural: rules, focus states, metadata, and selective emphasis.

Architecture

64rem navigation, 5xl main width, 58rem wide case header, 45rem article measure.

Cases, Topics, Concepts, Method, About, and the case reading flow remain intact.
